# 多Agent协作平台 MVP 实现计划 - Phase 6: 前端核心页面

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 实现6个核心前端页面：Agent管理、项目管理、工单看板、工单详情、工具调试、审批中心。同时优化Dashboard首页。

**Architecture:** 替换Phase 5的占位页面为完整功能页面。每个页面独立，可并行开发。

**Tech Stack:** React 18 + Ant Design 5 + Zustand + Axios + React Router v6

---

## Task 1: Dashboard 首页

**Files:**
- Modify: `apps/frontend/src/pages/Dashboard.tsx`

实现：
- 显示平台概览卡片（Agent数量、项目数量、待处理工单数、待审批数）

- AntD Card + Statistic 展示统计

**Files:**

## Task 4: 工单看板页

**Files:**
- Modify: `apps/frontend/src/pages/Tickets.tsx`

实现：
- 四列看板布局（待分配 / 进行中 / 待审核 / 已完成）
- 每列显示工单卡片（标题、优先级Tag、类型Tag、指派人）
- 顶部项目选择器（Select选择当前项目）
- 新建工单按钮（Modal表单：标题、描述、类型、优先级、指派Agent）
- 点击工单卡片跳转到工单详情页 /tickets/:id
- 工单状态流转（点击按钮推进状态）

---

## Task 5: 工单详情页

**Files:**
- Modify: `apps/frontend/src/pages/TicketDetail.tsx`

实现：
- 顶部工单信息（标题、状态、优先级、指派人、创建时间）
- 状态操作按钮（推进/退回）
- 对话消息列表（按时间排序，区分 user/agent/system 消息）
  - thought 类型：灰色背景，折叠展示
  - action 类型：蓝色标签
  - observation 类型：绿色背景
  - text 类型：正常气泡
- 底部消息输入框（用户发送消息）
- 触发Agent执行按钮（POST /api/agents/:id/execute）
- 执行结果展示（iterations、completed、error）

## Task 6: 工具调试页

## Task 7: 审批中心页

**Files:**
